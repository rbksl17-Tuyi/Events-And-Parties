Diego Pérez Robeta

2. Datos personales

Cuando una persona solicita información o presupuestos por WhatsApp o correo, podemos tratar su nombre, teléfono, correo electrónico y datos del evento que facilite voluntariamente.

3. Finalidades

Los datos se utilizan para responder consultas, elaborar presupuestos, gestionar los servicios contratados y cumplir obligaciones legales.

4. Base jurídica

El tratamiento para atender solicitudes y gestionar contrataciones se basa en medidas precontractuales o en la ejecución de un contrato. Las obligaciones fiscales se atienden sobre la base del cumplimiento legal.

5. Conservación

Los datos se conservarán durante el tiempo necesario para las finalidades indicadas y, cuando corresponda, durante los plazos legales aplicables.

6. Destinatarios

Podrán intervenir proveedores tecnológicos necesarios para prestar los servicios, incluidos servicios de mensajería y alojamiento web. Las transferencias internacionales, si existen, estarán sujetas a las garantías legalmente exigibles.

7. Derechos

Puedes solicitar el acceso, rectificación, supresión, oposición, limitación y portabilidad de tus datos cuando corresponda, escribiendo a perezrobeta@gmail.com.

También puedes presentar una reclamación ante la Agencia Española de Protección de Datos: www.aepd.es.

8. Seguridad

Se aplicarán medidas técnicas y organizativas apropiadas para proteger los datos personales.

9. Servicios externos

Esta web utiliza enlaces a servicios externos como WhatsApp e Instagram, que disponen de sus propias políticas de privacidad.
